# 上蔟 · 熟蚕找格解谜

一个以蚕农“上蔟”为题材的 TypeScript + PixiJS + Web Worker 解谜游戏。每条熟蚕都有独立的位置、体型、体力、朝向、找格目标和轨迹；Worker 固定步长推演，PixiJS 负责蔟片、蚕群、茧、平板丝和轨迹回看的绘制。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的地址。生产构建：

```bash
npm run build
npm run preview
```

类型检查：

```bash
npm run typecheck
```

无浏览器平衡推演：

```bash
npm run balance        # 六个关卡的“不翻 / 控设备+翻蔟”对照
npm run balance:matrix # 更多翻蔟时间矩阵
```

## 页面

- `#/setup` **蔟架布置页**：六关、五种蔟片规格、六种光照布局；可预览蔟片格数、备用空蔟、初始倾角、灯和风扇。
- `#/live` **上蔟实况页**：PixiJS 画布、实时上茧率/双宫茧率/平板丝、倾角滑杆、全部或单张翻蔟、灯/风扇、暂停/倍速、点选蚕和手动捡到空蔟。
- `#/replay` **单蚕轨迹回看页**：按编号或平板丝/双宫茧/被手拣/好茧列表选蚕，播放、暂停、拖动时间轴、变速、点击事件跳转。
- `#/result` **关卡评星页**：按上茧率、双宫茧率、平板丝率给出 0–3 星，并展示账本和复盘建议。

快捷键：`Space` 暂停，`F` 翻全部蔟片，`L` 灯，`V` 风扇，`P` 拣蚕模式。

## 行为模型

每条蚕在 `src/sim/engine.ts` 中按固定步长更新，移动方向由这些规则共同决定：

1. **向上爬**：基础方向始终朝向蔟片上方。
2. **倾角偏向高端**：方向中加入 `sin(tilt)` / `-cos(tilt)`，滑杆从负到正会让蚕群重新偏向新的高端。
3. **避光**：在蚕的左右、上下归一化光照传感器采样，沿亮度梯度反方向转向；前方有强光斑时触发掉头。关灯会去掉灯光源，但窗户光仍然存在。
4. **找四角遮挡格**：对附近空格按四壁遮挡、黑暗度、体型匹配、上方/高端偏好和距离评分；角格和边格有额外遮挡加成。
5. **试壁**：进入候选格后绕格心运动一圈，检查四壁；遮挡不足、格内过亮、太大或太小都会退出继续找。
6. **拥挤与双宫茧**：格内已有茧或已过极短同入窗口时，后来蚕会绕行；只有几乎同一模拟窗口进入同一格的两条蚕才按关卡设定概率结双宫茧，概率失败时一条留格、另一条被挤出。
7. **体力与平板丝**：找得越久、光越强、室内越闷热，体力消耗越快；风扇显著降低闷热消耗。体力归零即在当前位置留下灰色平板丝。
8. **翻蔟**：蚕、格内茧、检查员和格位一起做 180° 映射，原高端蚕群会到新的下端并重新向新高端找格。翻后短时间内清除“乱爬挫败值”、扩大找格半径并临时预留目标格，因此合适时机能明显提高上茧率。
9. **手动拣蚕**：点击乱爬/试壁中的蚕，再送到选中的备用空蔟；会重置当前格、恢复部分体力并给予新的找格宽限。

## 平衡结果

第 1 关使用固定种子，无头 Worker 同款引擎的近期测量：

| 策略 | 上茧率 | 双宫茧率 | 平板丝 | 星 |
| --- | ---: | ---: | ---: | --- |
| 一次不翻 | **59.2%** | 1.4% | 47 张 | 1 |
| 约 12–56 秒内选合适时机翻一次 | **90–98%** | 0.8–5.3% | 0 张 | 3 |
| 24 秒 + 52 秒翻两次 | **91.7%** | 4.3% | 0 张 | 3 |

浏览器冒烟脚本以 4× 速度、约第 30 秒和第 60 秒翻全部蔟片跑完整 UI，曾得到 **96.7% 上茧率 / 1.7% 双宫茧率 / 0 平板丝 / 3 星**。第 2、4、5、6 关在关灯、开风扇并适时翻蔟的无头策略下也可达到三星区间；第 3 关因大小蚕混规格，通常需要额外手动捡出反复退出密眼格的大蚕。

## 性能与数据

- 模拟状态使用 `Float32Array` / `Uint8Array` / `Uint16Array` / `Int32Array`，最多支持配置中的 3200 条蚕。
- Worker 每次快照转移类型化数组 buffer，避免结构化复制大数组。
- 轨迹每 0.2 秒采样 `t, x, y, state, stamina, sheetIndex`；回看时只向 Worker 请求单条蚕的 `Float32Array`。
- PixiJS 一个动态 `Graphics` 层批量绘制全部蚕，静态蔟片/格线/标签只绘制一次。
